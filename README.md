## Featured projects

### [Outlook Command Center](https://github.com/bh-automation/outlook-command-center)
Outlook task-pane add-in that gives every message exactly one status (ACTION, WAITING, PROJECT, DONE, REFERENCE) – no deleting, moving or sending, minimal permission (`ReadWriteItem`), no tracking.

- 39/39 browser end-to-end checks with an Office.js mock
- 8/8 logic tests and a repository validator (manifest, CSP, forbidden APIs)
- CodeQL analysis and GitHub Pages deployment via GitHub Actions
- Actions pinned to commit SHAs

### [Gmail Automation](https://github.com/bh-automation/gmail-automation)
Local, rule-based Gmail labelling and reply drafts for Windows. DRY-RUN by default; sending and deleting are blocked in the application; every change is audited and can be undone.

- 356 automated tests
- CI on Windows and Ubuntu, Python 3.12 / 3.13, PowerShell 5.1 / 7
- Separate read-only and write OAuth profiles
- Secret and forbidden-content scans as release gates; tagged v1.0.0
